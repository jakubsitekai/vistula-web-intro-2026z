# Pull requests — zasady dla studentów

To repozytorium służy do publikowania materiałów i zgłaszania linków do wykonanych projektów.

**Studenci:** proponujcie PR zmieniający wyłącznie nowy plik `submissions/TWOJ_LOGIN.md`. Nie zmieniajcie plików strony, sylabusa ani plików innych studentów. Jeden student = jedno zgłoszenie (można aktualizować).
Repozytorium studenta zawiera kod i działającą aplikację. Tutaj przekazujemy tylko linki.

PR stanowi zgłoszenie także wtedy, gdy nie zostanie zmergowany. Prowadzący może przyjąć zaliczenie na podstawie otwartego PR. Kurs oraz oceny znajdują się na stronie i w systemie uczelni.

Instrukcja krok po kroku: [submissions/README.md](submissions/README.md).
